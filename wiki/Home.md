# PyMessenger Home

## Overview
PyMessenger is a Python tool for local-network messaging over the same Wi‑Fi. It is focused on office environments where users want quick communication without needing internet access.

## Homepage
- https://showcase-atlaspymessenger281912.lovable.app

## Core features
- Nearby device discovery on the LAN
- Device list with active/inactive status
- Direct 1-on-1 chat
- Privacy/stealth controls
- Network workspace dashboard
- Automated message reliability checks

## Current project state
The app is functional as a prototype/demo and includes a strong base for future work. The repo is light but complete enough to demonstrate the feature set.
